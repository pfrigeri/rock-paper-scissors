# 🎮 Pedra, Papel e Tesoura - Jogo com UI

Um jogo clássico de Pedra, Papel e Tesoura com uma interface interativa construída com JavaScript puro.
Este projeto foi desenvolvido como um exercício prático do currículo do [The Odin Project](https://www.theodinproject.com/) para solidificar conceitos fundamentais de manipulação do DOM e gerenciamento de eventos.

**[➡️ Jogue a versão ao vivo aqui!](https://pfrigeri.github.io/rock-paper-scissors/)**

---

## ✨ Funcionalidades

* Interface interativa com botões para cada escolha do jogador.
* Geração de jogada aleatória para o computador a cada rodada.
* Feedback visual imediato para cada rodada (vitória, derrota ou empate).
* Placar que atualiza em tempo real.

## 🛠️ Tecnologias Utilizadas

* HTML5
* CSS3
* JavaScript (Vanilla JS)

## 🧠 O que eu aprendi

Este projeto foi uma oportunidade incrível para praticar e entender:

* **Manipulação do DOM:** Selecionar elementos com `querySelector` e atualizar seu conteúdo com `.textContent`.
* **Gerenciamento de Eventos:** Usar `addEventListener` para capturar cliques e a técnica de **Event Delegation** para um código mais limpo.
* **Lógica de Jogo:** Implementar as regras do jogo e gerenciar o estado (placar) através de variáveis.
* **Refatoração:** A importância de reestruturar o código ao passar de uma aplicação de console para uma com interface gráfica.
